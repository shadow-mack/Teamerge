Parallel coding agents,
together.

Teamerge is a desktop app for teams that run coding agents in parallel. Every task gets its own git worktree, and every teammate’s agents show up in one window, live, from their own laptops.

Download for macOS Source on GitHub

Open source · MIT · macOS · no account needed

Built for the hard part of parallel work.

Starting agents is easy. Knowing who is changing what, handing work between people and landing it all without conflicts is not.

Every agent, its own worktree

Claude Code, Codex and the rest each work in a real checkout, so attempts never overwrite each other.

Your whole team in one window

Teammates’ agents appear in the Team hub while they run on their own machines.

Hand off and take over

Hand a task to a teammate with a drafted brief. They press Take and their agent continues on the same branch.

Review, typed into the agent

Reviewers comment on lines from their machine, and the comments go straight to your agent.

Warnings before tasks collide

See the files each task shares with others, claim files, and get warned before a merge would conflict.

Race, then land

Give one task to several agents, keep the best run, and land finished work in order with Land All.

No account. End-to-end encrypted.

Your identity is a key pair on your Mac, and the team roster is a file in your repository. Traffic goes through a relay your team hosts, which only ever sees sealed envelopes.

  1. Create a team from the Team hub, or host the relay on your Mac.
  2. Push .teamerge/team.json so teammates can find it.
  3. Teammates join from the same repository, and their agents appear in your window.

A CLI your agents use too.

The app puts teamerge on every agent’s PATH.

teamerge context        # who is working on what, here and on teammates' machines
teamerge why src/app.ts # who is changing a file, and why
teamerge risk           # exit code 3 when merging this task would conflict
teamerge claim src/db/  # tell other agents you're on it
teamerge send alex "rebased on main, take a look"
